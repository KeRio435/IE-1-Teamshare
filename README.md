# IE-1-Teamshare
Working teamshare mode on melonDS emulator PC only for IE 1 on NDS only

Program działa na zasadzie udostępniania plików .sav z emulatora MelonDS gry z przygotowaną drużyną w teamshare mode innym osobą dzięki temu jest możliwość rozegrania meczu z drużyną innego gracza offline

Tutorial how to use
If you want to share your team with others

1. From the main menu, go to ‘Connect’
2. Then select ‘Teamshare mode’
3. Select ‘Settings’
4. Go to ‘Create profile’, where you can write a message that will be displayed to other players
5. Once you’ve written your message, go to ‘Organise Team’, select the players you want to include in the team, and choose their positions and formation
6. Then go to ‘Team Name and Emblem’, where you can enter your team’s name and select an emblem
7. Finally, go to ‘Change Strip’ and change the players’ kits to whatever you like

PLEASE NOTE: when the game asks if you want to save, ALWAYS select ‘Yes’ so that your settings are saved

Once you’ve finished, go to the folder where you’ve stored Inazuma Eleven 1 for the NDS. Under your game’s name, you’ll find a file with the .sav extension that has the same name as your game
Now send it to another player to share your team with others.

Before using the programme, ALWAYS make a backup copy of your save file (.sav)

If you want to play with a team created by another player:
1. You must have their .sav file.
2. Launch ie_teamshare_transfer.exe.
3. Under ‘Source with teamshare’, select the other player’s .sav file.
4. Under ‘Target’, select your .sav file
5. Then go to ‘Add / replace / remove teams in the target’s teamshare’ and click ‘Add team from source’
6. Then click ‘Save output file’
7. Rename the saved .sav file to match the name of your .sav file
8. Place the .sav file in your game folder and launch MelonDS
9. Have fun :D
